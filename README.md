# Duplicate Question Detection App

ML + NLP application using **TF-IDF and Linear SVM** to identify duplicate question pairs, achieving **80.6% accuracy**, with an interactive **Streamlit** interface.
## Dataset

This project uses the Quora Duplicate Question dataset containing
345,036 question pairs.

The dataset contains the following columns:

- index
- id
- qid1
- qid2
- question1
- question2
- is_duplicate

The dataset is not included in this repository because of its relatively
large file size (~46 MB).
